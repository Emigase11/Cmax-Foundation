# Unified public action index

The public index at `/our-actions` reads both collections. Keystatic collections,
detail routes and the `action:` / `campaign:` support references remain separate.

Editorial decision: keep Ukraine, Haiti and Argentina published. Their cards
state that documentation is being compiled and confirmed results are not yet
published. This is based on an empty `outcomes` array, not on a status badge.
No source content or publication flags were changed.

Proposals are presented as proposals, with existing recipient confirmation text.
The exact `/campaigns` index permanently redirects; campaign detail paths do not.
